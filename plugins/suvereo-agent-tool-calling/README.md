# Suvereo Tool Calling Agent

Base implementation of a tool-calling agent for Suvereo, built on top of LangChain's tool-calling framework. This package provides the `BaseToolCallingAgent` class that all Suvereo agents extend.

## Installation

This package is a dependency of other Suvereo agent plugins and is installed automatically alongside them. To install it directly:

```shell
pip install suvereo-agent-tool-calling
```
